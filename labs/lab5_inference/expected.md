# Lab 5 预期结果

## 主表

```
[1] KV cache：逐 token 生成 80 步
  无缓存     3.8 ms
  有缓存     1.8 ms
  加速比    2.10×

[2] 量化：2048×2048 权重矩阵
  fp32   16.8 MB  ->  int8    4.2 MB（4×）
  相对误差 0.90%

[3] 投机解码：γ=4, c=0.05
  α=0.3 → 1.83×
  α=0.7 → 3.17×
  α=0.9 → 3.83×
```

耗时随机器波动，**比值应当稳定**。

## 怎么读

| 现象 | 解释 |
|---|---|
| KV cache 2.1× | 80 步时 $O(n^2)$ 与 $O(n)$ 的差距 |
| 量化 4× 压缩 | 32 bit → 8 bit |
| 相对误差 0.9% | 逐通道对称量化的典型水平 |
| α 越高加速越大 | 分子 $1+\alpha\gamma$ 线性增长 |
| c 越大加速越小 | 分母 $1+\gamma c$ 线性增长 |

## 注意

- KV cache 只测注意力部分，完整模型加速比通常只有 1.5–2×；
- 量化误差与权重分布有关，`randn * 0.02` 是比较温和的情形。

## 常见失败与排查

| 现象 | 原因 |
|---|---|
| 加速比 < 1 | 计时太短，被 Python 开销淹没（把 steps 调大） |
| 量化误差异常大 | scale 算错（应除以 127，不是 128） |
| 投机加速比 > 4 | 公式里 γ 或 c 传错 |

## 通过标准

- KV cache 加速比在 1.5–3× 之间
- 量化压缩比约 4×，相对误差 < 2%
- α=0.7 时投机加速比约 3×
