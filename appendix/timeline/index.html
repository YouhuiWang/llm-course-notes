    大模型发展时间线¶

    本页由 refs/timeline.yaml 自动生成，请勿手工编辑。 运行 python scripts/gen_timeline.py 更新。

    共收录 57 个节点，覆盖 1943–2026 年。

    1940s¶

    时间 事件 类别 一句话
    1943-01 麦卡洛克-皮茨神经元
    McCulloch-Pitts Neuron    		 🧠 理论 用阈值逻辑单元描述神经活动，奠定"计算单元"的抽象。

    1950s¶

    时间 事件 类别 一句话
    1950-10 图灵测试
    Computing Machinery and Intelligence    		 🧠 理论 把"机器能否思考"转化为可操作的行为判据。
    1958-07 感知机
    The Perceptron    		 🧠 理论 第一个可学习的线性分类器，也暴露了线性不可分的局限。

    1980s¶

    时间 事件 类别 一句话
    1986-10 反向传播
    Backpropagation    		 🧠 理论 用链式法则高效计算多层网络梯度，深度学习的前置条件。

    1990s¶

    时间 事件 类别 一句话
    1997-11 长短期记忆网络
    LSTM    		 🏗️ 架构 用门控与细胞状态缓解梯度消失，统治序列建模近二十年。

    2000s¶

    时间 事件 类别 一句话
    2003-06 神经网络语言模型
    A Neural Probabilistic Language Model    		 🏗️ 架构 首次用稠密词向量 + 前馈网络做语言建模，困惑度显著优于 n-gram。

    2010s¶

    时间 事件 类别 一句话
    2013-01 word2vec
    Efficient Estimation of Word Representations    		 🏗️ 架构 负采样 + 层次 softmax 让词向量训练可规模化，语义算术成为现象级演示。
    2014-09 序列到序列学习
    Sequence to Sequence Learning    		 🏗️ 架构 编码器-解码器结构统一了翻译等变长映射任务。
    2014-09 加性注意力
    Neural Machine Translation by Jointly Learning to Align and Translate    		 🏗️ 架构 让解码器动态对齐源句片段，注意力的雏形。
    2015-12 残差连接
    Deep Residual Learning    		 🏗️ 架构 恒等捷径让上百层网络可训练，成为 Transformer 的必备组件。
    2017-06 Transformer
    Attention Is All You Need    		 🏗️ 架构 完全用注意力替代循环，实现训练并行化，大模型时代的起点。
    2018-06 GPT-1
    Improving Language Understanding by Generative Pre-Training    		 🏗️ 架构 生成式预训练 + 下游微调，确立"预训练-微调"范式。
    2018-10 BERT
    Bidirectional Encoder Representations from Transformers    		 🏗️ 架构 双向掩码语言建模刷新 11 项 NLP 任务，编码器路线的高峰。
    2019-02 GPT-2
    Language Models are Unsupervised Multitask Learners    		 📈 规模 15 亿参数，零样本迁移初现，因滥用风险分阶段发布。
    2019-10 T5
    Exploring the Limits of Transfer Learning    		 🏗️ 架构 把一切任务统一为"文本到文本"，系统比较预训练目标与规模。

    2020s¶

    时间 事件 类别 一句话
    2020-01 缩放定律
    Scaling Laws for Neural Language Models    		 📈 规模 损失随参数量、数据量、算力呈幂律下降，为"堆规模"提供定量依据。
    2020-05 GPT-3
    Language Models are Few-Shot Learners    		 📈 规模 1750 亿参数，少样本上下文学习成为新范式。
    2020-10 ViT
    An Image is Worth 16x16 Words    		 🏗️ 架构 图像切 patch 直接送进 Transformer，视觉与语言架构开始统一。
    2021-01 Switch Transformer
    Switch Transformers    		 🏗️ 架构 万亿参数稀疏 MoE，验证"参数量与计算量解耦"的可行性。
    2021-01 CLIP
    Contrastive Language-Image Pre-training    		 🏗️ 架构 4 亿图文对对比学习，得到可零样本分类的共享嵌入空间。
    2021-04 RoPE
    RoFormer: Rotary Position Embedding    		 🏗️ 架构 用旋转矩阵编码相对位置，成为长上下文模型的事实标准。
    2021-06 LoRA
    Low-Rank Adaptation    		 ⚙️ 系统 用低秩增量冻结主干，把微调显存需求降低一个数量级。
    2021-07 Codex
    Evaluating LLMs Trained on Code    		 🚀 应用 代码预训练带来程序合成能力，GitHub Copilot 的技术基础。
    2022-01 InstructGPT
    Training Language Models to Follow Instructions with Human Feedback    		 🎯 对齐 RLHF 三阶段流程成型，1.3B 模型的人类偏好超过 175B 基座。
    2022-03 Chinchilla
    Training Compute-Optimal Large Language Models    		 📈 规模 参数与数据应同比扩展，多数模型此前严重训练不足。
    2022-05 FlashAttention
    Fast and Memory-Efficient Exact Attention with IO-Awareness    		 ⚙️ 系统 用分块与在线 softmax 把注意力做成 IO 最优，长序列训练成为可能。
    2022-11 ChatGPT
    ChatGPT    		 🚀 应用 对话式交互把大模型推向大众，两个月用户破亿。
    2023-02 LLaMA
    Open and Efficient Foundation Language Models    		 🔓 开源 小模型 + 充分数据达到强性能，开源生态由此爆发。
    2023-03 GPT-4
    GPT-4 Technical Report    		 📈 规模 多模态输入 + 大幅提升的推理与考试表现，闭源路线的标杆。
    2023-05 DPO
    Direct Preference Optimization    		 🎯 对齐 把 RLHF 目标解析地转成分类损失，偏好对齐不再需要 RL 循环。
    2023-07 Llama 2
    Llama 2    		 🔓 开源 开放商用许可，配套对话模型与安全报告，开源进入产品化阶段。
    2023-09 Mistral 7B
    Mistral 7B    		 🔓 开源 滑窗注意力 + GQA，小模型效率标杆。
    2023-12 Mixtral 8x7B
    Mixtral of Experts    		 🏗️ 架构 开源稀疏 MoE 首次在通用任务上追平更大稠密模型。
    2024-02 Gemini 1.5
    Gemini 1.5    		 🏗️ 架构 MoE + 百万级 token 上下文，长上下文成为竞争维度。
    2024-05 DeepSeek-V2 / MLA
    DeepSeek-V2    		 ⚙️ 系统 多头潜在注意力压缩 KV cache，推理成本大幅下降。
    2024-05 GPT-4o
    GPT-4o    		 🚀 应用 文本/视觉/语音端到端统一，交互延迟接近实时对话。
    2024-09 o1
    Learning to Reason with LLMs    		 🎯 对齐 用 RL 训练长思维链，把"测试时计算"变成可扩展的能力维度。
    2024-11 MCP
    Model Context Protocol    		 ⚙️ 系统 统一模型与外部工具/数据源的连接方式，agent 生态的接口标准。
    2024-12 DeepSeek-V3
    DeepSeek-V3 Technical Report    		 🔓 开源 671B MoE、14.8T token 预训练，训练成本与性能比刷新认知。
    2025-01 DeepSeek-R1
    DeepSeek-R1    		 🎯 对齐 纯 RL（R1-Zero）涌现反思与长链推理，推理能力可被蒸馏到小模型。
    2025-01 DeepSeek-R1
    DeepSeek-R1    		 🎯 对齐 纯 RL 训练的长链推理模型，开源 MIT 许可，并蒸馏出 6 个小模型。
    2025-02 Claude 3.7 Sonnet
    Claude 3.7 Sonnet    		 🏗️ 架构 首个"混合推理"商用模型：同一模型可切换即时回答与扩展思考。
    2025-03 Gemini 2.5 Pro
    Gemini 2.5 Pro    		 🏗️ 架构 100 万 token 上下文的思考型模型，长上下文与推理结合。
    2025-04 ⚠️ Qwen3
    Qwen3    		 🔓 开源 稠密与 MoE 并行的开源家族，支持思考/非思考模式切换。
    2025-04 Llama 4（MoE + 1000 万上下文）
    Llama 4 Scout / Maverick    		 🔓 开源 首个 Llama MoE 系列，Scout 宣称 1000 万 token 上下文，原生多模态。
    2025-04 Qwen3（混合思考）
    Qwen3    		 🔓 开源 235B-A22B 旗舰 MoE，同一模型支持思考/非思考模式，Apache 2.0。
    2025-05 Claude 4（Opus 4 / Sonnet 4）
    Claude 4    		 🚀 应用 主打编码与 agent 场景，Claude Code 正式可用。
    2025-07 Kimi K2
    Kimi K2    		 🔓 开源 1T 总参数 / 32B 激活的开源 MoE，用 Muon 优化器训练，主打 agent 能力。
    2025-08 GPT-5（路由式统一系统）
    GPT-5    		 🏗️ 架构 用实时路由在"快模型"与"推理模型"之间自动切换，开箱即用。
    2025-08 gpt-oss（OpenAI 重新开源）
    gpt-oss-120b / 20b    		 🔓 开源 OpenAI 自 GPT-2 之后首次发布开放权重模型，Apache 2.0。
    2025-11 Gemini 3 Pro
    Gemini 3 Pro    		 🚀 应用 Gemini 3 首款模型，多模态与长上下文继续保持领先。
    2025-12 DeepSeek-V3.2（稀疏注意力）
    DeepSeek-V3.2    		 🏗️ 架构 引入 DeepSeek Sparse Attention，并把思考能力整合进工具调用。
    2026-01 ⚠️ Kimi K2.5（原生多模态）
    Kimi K2.5    		 🔓 开源 约 15T 图文混合 token 训练，1T 总参数 / 32B 激活。
    2026-02 ⚠️ Qwen3.5（原生视觉）
    Qwen3.5-397B-A17B    		 🔓 开源 Qwen 首个带原生视觉的开源旗舰，Apache 2.0。
    2026-02 ⚠️ GLM-5
    GLM-5    		 🔓 开源 744B 总参数 / 40B 激活，采用稀疏注意力，MIT 许可。
    2026-03 ⚠️ GPT-5.4（100 万上下文 + 内置电脑操作）
    GPT-5.4    		 🚀 应用 首个 1M 上下文并内置 computer use 的 GPT-5 系列模型。
    2026-04 ⚠️ Gemma 4
    Gemma 4    		 🔓 开源 开源多模态系列，支持文本/图像/音频输入。

    读时间线的三个视角¶

    1. 架构线：RNN（1997）→ Attention（2014）→ Transformer（2017）→ MoE（2020/2024）→ 长上下文（2024）
    2. 规模线：NNLM（2003）→ GPT-3（2020）→ Scaling Laws（2020）→ Chinchilla（2022）→ 推理期扩展（2024）
    3. 对齐线：InstructGPT（2022）→ DPO（2023）→ o1/R1（2024–2025）

    三条线的交汇点，就是「能用的助手」出现的位置。
