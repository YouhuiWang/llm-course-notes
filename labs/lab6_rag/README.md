## 四个关键点

### 1 为什么不用真的嵌入模型

预训练嵌入模型动辄几百 MB，还要下载。本实验用 **TF-IDF + SVD** 代替：它同样把文档映射到稠密向量，同样用余弦相似度排序——**结构完全一样，只是没"训练过"**。

理解了这条链路，换成真模型时只需要替换 `LSA` 这一个类。

### 2 RRF 为什么不需要归一化

BM25 的分数是 0–20，余弦相似度是 0–1，量纲不同，没法直接相加。

RRF 只用**排名**：$\frac{1}{60+\text{rank}}$。这样两路可以无条件融合，不需要调权重。

### 3 忠实度为什么要"故意编一句"

如果答案全部从上下文抄，忠实度永远是 1.0，指标就失去了意义。

本实验让生成器在**检索不置信时**补一句上下文里没有的话——这正好模拟真实系统"证据不足就编"的行为。指标随之下降，你就能看到它起作用。

### 4 弱重排可能反而更差

实验里"混合 + 重排"并没有比"混合"更好。原因很直接：**玩具重排器的信号比检索本身还弱**。

真实系统用的是交叉编码器（把 query 与 doc 拼起来过一次模型），信息量远大于词面覆盖。这个反例说明：**重排不是万能药，信号弱的重排会引入噪声**。
