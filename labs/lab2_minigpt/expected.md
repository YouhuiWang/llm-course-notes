# Lab 2 预期结果

## 主输出

```
语料 3216 字符｜词表 184｜参数 0.48M
训练 800 步，batch 32，ctx 128

  step    1｜train 84.656｜val 81.573｜0s
  step   20｜train 69.272｜val 59.570｜1s
  step   40｜train 24.134｜val 18.600｜1s
  ...
  step  800｜train  0.989｜val  1.715｜18s

困惑度：5.6
```

时间取决于 CPU，慢一点（1–2 分钟）也正常。

## 三条曲线特征

| 阶段 | 现象 | 原因 |
|---|---|---|
| 0–40 步 | loss 从 84 快速掉到 20 | 初始 logits 过大，先学会"均匀输出" |
| 40–200 步 | 20 → 2.4 | 学到字符级统计规律 |
| 200–800 步 | 2.4 → 1.7 | 开始记忆语料 |

**注意第一步的 84**：这不是 bug。权重绑定 + 无缩放导致初始 logits 很大，softmax 接近 one-hot，交叉熵爆炸。几十步后自动修正。

## 怎么判断"训好了"

| 指标 | 期望值 | 说明 |
|---|---|---|
| val loss | 1.6–1.9 | 低于 1.5 说明过拟合 |
| 困惑度 | 5–7 | $e^{1.7}\approx5.5$ |
| train/val 差距 | < 1.0 | 差距大 = 过拟合 |
| 中文生成 | 基本通顺 | 能认出是中文 |
| 英文生成 | 大概率乱码 | 数据量不足 |

## 常见失败与排查

| 现象 | 原因 |
|---|---|
| loss 一直是 84 | 学习率太小，或梯度没回传 |
| loss 变 nan | 学习率太大，梯度爆炸（检查裁剪） |
| 生成全是同一个字 | 温度太低，或模型塌缩 |
| 生成全是乱码 | 训练步数不够（< 100） |
| 报错 `out of memory` | ctx 或 batch 太大，调小 |

## 通过标准

- 能跑完 800 步，val loss < 2.0
- 中文提示能生成可辨认的中文
- `results/loss.png` 曲线单调下降（允许抖动）
