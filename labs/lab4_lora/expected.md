# Lab 4 预期结果

## 主表

```
预训练：任务 A（判断序列和是否 > 36）
  参数 68K｜耗时 0.6s｜任务 A 准确率 0.973

微调：任务 B（判断首元素是否大于末元素）
方式          可训练参数    占比    耗时    准确率
full           68,354   100.0%   0.6s   0.952
lora            3,072     4.5%   0.5s   0.870
head              130     0.2%   0.2s   0.590
```

数值会小幅波动，但**排序必须一致**：full > lora ≫ head。

## 怎么读

| 现象 | 解释 |
|---|---|
| lora 只有 4.5% 参数 | 只训 A/B 两个低秩矩阵 |
| lora 准确率 0.87 < full 0.95 | 低秩有表达上限 |
| head 只有 0.59 | 预训练表示是"求和"，无法支持"比较首尾" |
| 耗时都在 1 秒内 | 模型太小，时间差异不显著 |

**关键**：head-only 的失败说明**适配位置比参数量更重要**。

## 常见失败与排查

| 现象 | 原因 |
|---|---|
| 三组准确率完全相同（如全 0.97） | 任务不平衡，模型在猜多数类 |
| `AttributeError: LoRALinear has no attribute weight` | 把 LoRA 加到了 `MultiheadAttention.out_proj` |
| lora 准确率等于 full | `set_trainable` 没冻结 base |
| 准确率全是 0.5 | 学习率太大，或数据标签写错 |

## 通过标准

- 三组都有输出，且 full ≥ lora > head
- lora 的可训练参数占比 < 10%
- head 的准确率明显低于 0.7
