# 习题参考答案要点

> 这里给的是**思路与关键数值**，不是完整解答。推导题请自己写完整过程，
> 实现题的代码以能跑通、能与参考实现对齐为准。

## 第 1 讲　大模型是什么

1. $6 = 2$（前向）+ $4$（反向），按每参数每 token 计。
2. 推理 $2NT$ 随 $N$ 线性；训练 $6ND$，按 $D=20N$ 是 $120N^2$，随 $N$ 平方。
3. $C=6\times70\times10^9\times1.4\times10^{12}=5.9\times10^{23}$；2048 卡、45% MFU ≈ **23.6 天**。
4. 陡峭度来自 $p^n$ 的 $n$ 次幂：$n$ 越大曲线越陡；指标越严（全对 vs 单步）$n$ 越大。

## 第 2 讲　统计语言模型

1. 每个历史都要存一个完整的后继分布，参数是 $|V|^n$。
2. PP=10 意味着平均在 10 个候选里犹豫；词表不同则候选空间不同，不可比。
3. $\sum_i \frac{c_i+1}{c+|V|}=\frac{c+|V|}{c+|V|}=1$。
4. $\mathrm{PP}=\exp(-\frac1T\sum\log p)=(\prod_t p_t)^{-1/T}$。

## 第 3 讲　神经序列建模

1. NNLM 约 $1.5\times10^7$，trigram 表 $1.25\times10^{14}$，差 7 个数量级；差在稀疏表 vs 稠密矩阵。
2. RNN 的衰减由权重谱半径固定；LSTM 由门控决定，可学。
3. $\operatorname{diag}(1-\tanh^2)$ 是 tanh 的导数，逐元素缩放梯度。
4. 把 $\boldsymbol{v}^\top\tanh(\cdot)$ 换成 $\boldsymbol{q}^\top\boldsymbol{k}$ 即 (L4.1)。

## 第 4 讲　注意力

1. $h$ 翻倍：参数不变、计算不变、$d_k$ 减半；头数不是免费，低秩约束更强。
2. 训练 $n\times n$（一次算完），推理 $1\times n$（只看历史）。
3. $\Var=d_k(\sigma_q^2\sigma_k^2+\mu_q^2\sigma_k^2+\mu_k^2\sigma_q^2)$；均值非零时缩放因子要相应调整。
4. $\boldsymbol{J}=\operatorname{diag}(\boldsymbol p)-\boldsymbol p\boldsymbol p^\top$；$p$ 均匀时梯度最大，趋近 one-hot 时趋零。

## 第 5 讲　Block 与范式

1. 差别在残差是否穿过 LN；深层时梯度要穿过每层 LN 的雅可比，会失控。
2. 训练目标与推理一致、可利用无标注文本、结构简单易扩展。
3. $12\times80\times8192^2\approx6.4\times10^{10}$，与 70B 级吻合。
4. $3d\,d_{\text{ff}}=4d^2\Rightarrow d_{\text{ff}}=4d/3$。

## 第 6 讲　Scaling Laws

1. Kaplan 时代普遍按 $D/N\approx1.7$ 配比，远低于 20，属训练不足。
2. 推理量大时，小模型多喂数据总成本更低；临界点由算力账算出。
3. $N\propto C^{\beta/(\alpha+\beta)}$；$\alpha=\beta$ 时指数为 0.5。
4. 临界服务量 $=\Delta C_{\text{train}}/\Delta C_{\text{per token}}$。

## 第 7 讲　GPT 谱系

1. 微调 → 零样本 → 少样本；参数 117M → 1.5B → 175B。
2. ICL 对顺序、标签噪声、格式都敏感，且参数不变——更像模式匹配。
3. $k=32$：$30+32\times40+20=1330$ token，是 $k=8$ 的 3.6 倍。
4. 边际示例的信息量递减，$k=4$ 后每例增益 < 1 个点。

## 第 8 讲　指令微调

1. SFT 学的是格式与行为，模式有限；知识在预训练里。
2. 去掉 mask：模型会把用户问题也当目标，学会"复述问题"而非"回答"。
3. $11/(26+500)\approx2\%$——长 system prompt 会严重稀释监督信号。
4. 精选 2000 条 ≈ 随机 5 万条（见 L8 图）。

## 第 9 讲　偏好优化

1. 同时加常数，差值不变；奖励只可辨识到常数，绝对刻度无意义。
2. 去掉 KL：奖励黑客（刷分）与语言退化（重复、格式崩坏）。
3. 拉格朗日求导得 $\pi^\star\propto\pi_{\text{ref}}e^{r/\beta}$；$Z(x)$ 对 $y_w,y_l$ 相同，相减抵消。
4. 求导得 $-\beta\sigma(-\beta\Delta)[\nabla\log\pi(y_w)-\nabla\log\pi(y_l)]$。

## 第 10 讲　安全对齐

1. 对齐税来自"能力"与"保守"的张力，只能沿前沿选点，不能消除。
2. 误拒伤体验、漏放出事故；例外：内部工具误拒代价低，可以偏严。
3. 令两策略总代价相等：$\Delta_{\text{漏}}/\Delta_{\text{误}}= (80-20)/(44-6)\approx1.6$。
4. 阈值升高 → 精确率升、召回降；曲线是单调的。

## 第 11 讲　MoE

1. 显存要放全部专家权重；算力只算被激活的 top-k。
2. 被选中的专家学得更快 → 更常被选，正反馈；打破：辅助损失、可学 bias、热身期均匀路由。
3. 重归一化后 $\sum g_i=1$；不归一化则输出尺度随 top-k 变化。
4. $N\sum f_iP_i$，均匀时取最小值 1。

## 第 12 讲　长上下文

1. 高频维度转得快，超出训练长度后相位混叠，模型没见过这些相位。
2. 能装=显存放得下；能读=needle 找得到；能用=RULER 多跳推理。
3. $\theta_{32}=10000^{-64/128}=0.01$，$\lambda=2\pi/0.01\approx628$；32K 内转约 52 圈。
4. 指数 $d/(d-2)$ 来自保持低频维度的相对分辨率不变。

## 第 13 讲　推理系统

1. 每生成一个 token 要读一遍全部权重，瓶颈在显存带宽而非算力。
2. 碎片=预留浪费（60%–80%）；不够=容量不足，是两回事。
3. $2\times40\times5120\times8192\times2\ \text{B}=6.7$ GB；24 GB 卡最多并发 2–3 条。
4. $\gamma=6$：$(1+3)/(1+0.6)=2.5$；$\gamma=4$：$(1+2)/(1+0.4)=2.14$。

## 第 14 讲　训练系统

1. TP 每层两次 all-reduce，跨机带宽不够会被拖死。
2. ZeRO-3 每次前向都要 all-gather 参数，通信量涨 1.5 倍。
3. $13\times10^9\times2+13\times10^9\times14/8\approx48.8$ GB。
4. 气泡率 $(P-1)/(M+P-1)$；$M$ 越大气泡占比越小。

## 第 15 讲　上下文工程

1. 防止生成到一半被截断；不给会导致 JSON 解析失败、工具调用残缺。
2. 语法合法 ≠ 语义正确：`{"age": "三十"}` 合法但类型错。
3. 32K：系统 1K、工具 2K、上下文 24K、查询 1K、输出 4K。
4. 中间→开头，召回率提升约 30 个点。

## 第 16 讲　RAG

1. 块大 → 噪声多，相关片段被稀释，精度下降。
2. $k$ 小头部占优；$k$ 大更看重"两路都上榜"。
3. $1/65+1/62\approx0.0315$。
4. 块大小减半 → 块数翻倍 → 索引体积翻倍。

## 第 17 讲　Agent（一）

1. $p^n$；$0.9^{15}\approx0.206$。
2. 上下文是有损压缩：容量有限、顺序敏感、不可回溯。
3. 要 50% 成功率：$p=0.5^{1/n}$。
4. 显式计划便于审查与并行，但计划本身可能错，需要 replan。

## 第 18 讲　Agent（二）

1. 任务不可干净分解；子任务需频繁交换中间状态。
2. MCP 连工具/数据，A2A 连 agent；协议层次不同，不能合并。
3. 8 个 agent：全连接 28 条 vs 层级 7 条，4 倍。
4. $1-0.75^6\approx0.82$。

## 第 19 讲　多模态

1. 图像切成 patch 后与文本同为 token 序列，可共用同一套 Transformer。
2. 前向是固定的加噪公式，没有可学参数。
3. 信号方差 $\bar\alpha_t\sigma^2$，噪声方差 $1-\bar\alpha_t$，SNR $=\bar\alpha_t/(1-\bar\alpha_t)$。
4. 正样本 logit 1.6、三个负样本各 0.4：$e^{1.6}/(e^{1.6}+3e^{0.4})\approx0.52$。

## 第 20 讲　测试时计算

1. CoT 把 $P(\text{答案}\mid\text{题})$ 变成 $P(\text{答案}\mid\text{题},\text{推理})$，条件更充分。
2. $p<0.5$ 时投票放大错误；错误相关时投票无效。
3. $\sum_{i\ge4}\binom{7}{i}0.7^i0.3^{7-i}\approx0.874$。
4. 边际成本 4 倍，边际收益 −6 个点。

## 第 21 讲　推理模型

1. 有客观验证器时不需要人标；主观任务（写作、审美）不适用。
2. 冷启动解决"RL 早期输出全是乱码"；R1-Zero 靠基座本身已有推理能力。
3. $[1,1,0,0,0,0]$：均值 0.333、标准差 0.471，优势 $+1.41/-0.71$。
4. 长度涨 7.6 倍，准确率涨 2.5 倍；单位准确率的成本在上升。

## 第 22 讲　前沿

1. 视频模型学的是像素统计，不理解物理因果。
2. 回放最有效但贵；正则便宜但效果有限；LoRA 隔离不遗忘但不迁移。
3. $d=8192$ 时交叉点 $n=8192$。
4. 30% 回放：遗忘率更低，训练成本 +30%。

## 第 23 讲　评测与治理

1. 固定测试集终会被训进去；只能换基准、加私有集、改评测方式。
2. 自回归模型对"先出现的答案"有位置先验，且训练数据里第一个回答常是"标准答案"。
3. $0.35\times0.92+0.65\times0.78=0.829$，真实 0.78，虚高约 **4.9 个点**。
4. $\pm1.96\sqrt{0.8\times0.2/100}\approx\pm0.078$，即 72%–88%。

## 第 24 讲　综合实践

1. "快"不可测；换成 P95 延迟、首 token 时间、吞吐。
2. 宽了做不完；MVP 只做一类问题、一个数据源、一个模型。
3. 500 ms：网络 50 + 首 token 150 + 生成 10 token×30 = 500，检索要靠缓存。
4. 项目 B 总分约 0.77；最该补"工程完整"（权重 0.25、得分最低）。
