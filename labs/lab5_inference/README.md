## 实测结果

```
[1] KV cache：逐 token 生成 80 步
  无缓存     3.8 ms
  有缓存     1.8 ms
  加速比    2.10×

[2] 量化：2048×2048 权重矩阵
  fp32   16.8 MB  ->  int8    4.2 MB（4×）
  平均绝对误差 0.000143｜最大误差 0.000400
  相对误差 0.90%

[3] 投机解码：γ=4, 草稿代价 0.05
  接受率 0.3 → 1.83×
  接受率 0.7 → 3.17×
  接受率 0.9 → 3.83×
```

## 三个结论

**1. KV cache 的收益随长度增长**：80 步时 2.1 倍，步数越多差距越大（无缓存是 $O(n^2)$，有缓存是 $O(n)$）。

**2. 量化是"体积换精度"**：4 倍压缩，相对误差 0.9%——对推理几乎无损。

**3. 投机解码看两个数**：接受率 $\alpha$ 和草稿代价 $c$。$\alpha=0.7$ 时 3.17 倍，但 $c$ 从 0.05 涨到 0.2，加速比就掉到 2.11 倍。

## 关键实现

```python
def spec_speedup(alpha, gamma, cost_ratio):
    return (1 + alpha * gamma) / (1 + gamma * cost_ratio)
```

- 分子：一次验证能确认 $1+\alpha\gamma$ 个 token；
- 分母：成本是 $1+\gamma c$（一次目标前向 + γ 次草稿）。

## 注意

本实验的 KV cache 只测了**注意力部分**的耗时，没有跑完整模型。真实场景里加速比会被其他层稀释，通常只有 1.5–2 倍。
