## 三个结论

**1. 理论与模拟吻合到小数点后两位**：二项分布公式是对的。

**2. $p<0.5$ 时投票降低准确率**：$p=0.4$、$k=5$ 时从 0.40 掉到 0.32——错答案占多数。

**3. 成本涨得比准确率快**：$k$ 从 1 到 5，准确率 +8 个点，成本涨 4.4 倍。

## 关键实现

```python
def majority_theory(p, k):
    need = k // 2 + 1
    return sum(comb(k, i) * p**i * (1 - p)**(k - i) for i in range(need, k + 1))
```
