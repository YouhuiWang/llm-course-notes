## 常见失败与排查

| 现象 | 原因 |
|---|---|
| 注意力误差 ~1e-2 | 忘了除以 $\sqrt{d_k}$ |
| 因果掩码测试失败，但非因果通过 | `triu` 的 `diagonal` 写错，或用了 `tril` |
| 多头误差 ~1e-1 | reshape 顺序错，把 head 维和 seq 维搞混 |
| 出现 `nan` | 用了 `-inf` 做 mask，或朴素 softmax 溢出 |
| RoPE 跨度不为 0 | 角度没按位置缩放，或奇偶维配错 |
