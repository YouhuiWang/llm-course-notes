## 目标

验证多数投票的收益、复现过度思考、算清成本账。

## 运行

```bash
.venv/bin/python labs/lab8_test_time/main.py
```

## 实测结果

```
[1] 多数投票（理论与模拟）
  p=0.4, k=5 → 0.317（比单次更低）
  p=0.6, k=5 → 0.683
  p=0.8, k=5 → 0.942

[2] 过度思考
  4096 → 0.700（峰值）
 16384 → 0.500
 32768 → 0.390

[3] 成本账（p=0.6）
  k=1  → 准确率 0.600，每题成本 1.67
  k=5  → 准确率 0.683，每题成本 7.33
  k=15 → 准确率 0.787，每题成本 19.06
```

## 三个结论

**1. 理论 ≈ 模拟**：二项分布模型正确。

**2. $p<0.5$ 时投票降低准确率**：错答案占多数，投票放大劣势。

**3. 成本涨得比准确率快**：$k$ 从 1 到 5，准确率 +8 点，成本涨 4.4 倍。

## 前提

投票有效的前提是**错误独立**。如果 k 次采样共享同一个误区，投票无效——这正是 Lab7 "去反思"那组的表现。

## 注意

过度思考曲线是模拟出来的经验函数，不是真实模型测量。

## 思考题

1. $p=0.55$、$k=9$ 时投票后准确率是多少？
2. 为什么"错误独立"是前提？举一个不独立的例子。
3. 每次采样成本记为 1，$p=0.6$ 时"每题成本最低"的 $k$ 是几？
4. 过度思考曲线的峰值位置由什么决定？
