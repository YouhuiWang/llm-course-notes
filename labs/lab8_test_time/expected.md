# Lab 8 预期结果

## 主表

```
[1] 多数投票：理论 vs 模拟
    p    k        理论        模拟
  0.4    5     0.317     0.321
  0.6    5     0.683     0.678
  0.8    5     0.942     0.940

[2] 过度思考
  4096 → 0.700（峰值）
 16384 → 0.500

[3] 成本账（p=0.6）
  k=1  0.600  每题成本 1.67
  k=5  0.683  每题成本 7.33
  k=15 0.787  每题成本 19.06
```

模拟值有小幅随机波动（20000 次试验，标准误约 0.003）。

## 怎么读

| 现象 | 解释 |
|---|---|
| 理论 ≈ 模拟 | 二项分布模型正确 |
| $p=0.4$ 时投票变差 | 错答案占多数，投票放大劣势 |
| $p=0.8$ 时提升最大 | 优势被放大 |
| 每题成本随 k 线性涨 | 准确率对数涨 |

## 关键洞察

投票的前提是**错误独立**。如果 k 次采样共享同一个误区（比如都漏看了一个条件），投票无效——这正是 Lab7 里"去反思"那组的表现。

## 常见失败与排查

| 现象 | 原因 |
|---|---|
| 模拟值偏离理论 > 0.02 | trials 太少 |
| 过度思考曲线单调上升 | 衰减项没生效（检查 `tokens > peak`） |
| 成本算错 | 用了"每次成本"而不是"总成本/准确率" |

## 通过标准

- 理论与模拟的差 < 0.02
- $p=0.4$ 时投票后低于单次
- 过度思考曲线在 4096 附近出现峰值
